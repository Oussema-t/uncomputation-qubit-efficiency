Uncomputation with U† — where the qubits go

A subroutine that computes a value into scratch qubits leaves them entangled with the data register. Until they are cleaned up they are garbage: they cannot be reused, and they act as a which-path record that destroys interference. Applying the inverse, U†, disentangles the scratch and returns it to |0⟩ exactly — so the same physical qubits serve every step.

U_logical |x⟩ = exp( i · Σk θk pk(x) ) |x⟩  —  pk(x) = conjunction of 3 signed literals, computed via 2 Toffolis into 2 scratch qubits

Logical damage — does the garbage actually matter?

Comparing each scenario's data register against the state the logical operation should produce. On a computational-basis input the garbage is just a deterministic label and costs nothing. On a superposition it records which path the computation took, and the coherence is gone — uncomputation is then required for correctness, not merely to save qubits.

How this is computed

Scenario B (n_data + 2 qubits) is simulated in full: a real complex state vector, Toffolis and phase gates applied amplitude by amplitude, with U† built by reversing the gate list and negating phase angles. Reduced density matrices come from a genuine partial trace; entropy comes from eigenvalues (Jacobi rotation on the real embedding of the Hermitian matrix), not from a closed-form shortcut.

Scenario A needs 2^(n_data + 2N) amplitudes, so it is simulated in full only while that fits the browser budget (). Beyond it, its reduced data state is obtained from an exact structured model, valid here because every compute step is a classical reversible Boolean map and every use is diagonal in the computational basis. Where both methods run, the page checks them against each other and reports the deviation below. Qubit counts are exact at every N — they are structural.

This page uses its own seeded generator, so its predicates differ from the Python benchmark's even at the same seed. The structural results (qubit counts, entropy before/after, the basis-vs-superposition contrast) are the same either way.
